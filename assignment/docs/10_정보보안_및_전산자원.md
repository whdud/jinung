# 전산자원 이용 안내

> 본 문서는 지능정보시스템 과제용으로 작성된 가상의 안내임. 실제 안내가 아님.

## 1. 계정

학생에게는 입학과 동시에 전산 계정을 발급한다. 계정은 학사정보시스템, 교내 무선망, 도서관 전자자료, 학습관리시스템에 공통으로 사용한다. 비밀번호는 6개월마다 변경하여야 하며, 변경하지 않은 계정은 일시 정지한다.

## 2. 교내 무선망

교내 무선망은 전산 계정으로 접속한다. 개인 공유기의 사용은 금지한다. 무선망에서 대용량 파일을 내려받는 경우 속도를 제한할 수 있다.

## 3. 실습실

컴퓨터공학부 실습실은 학기 중 평일 오전 9시부터 오후 10시까지 개방한다. 주말과 공휴일에는 사전 신청한 학생에 한하여 개방한다. 실습실 PC에 설치한 프로그램은 재부팅 시 초기화되므로 작업 결과는 개인 저장소에 보관하여야 한다.

## 4. GPU 서버

학부 GPU 서버는 졸업프로젝트와 교과목 실습을 위하여 운영한다. 사용을 원하는 학생은 담당 교원의 승인을 받아 신청한다. 1인당 동시 사용 가능한 GPU는 1장으로 제한하며, 연속 사용 시간은 24시간을 초과할 수 없다. 장기 작업이 필요한 경우 별도로 신청한다.

## 5. 금지 행위

타인의 계정을 사용하거나 빌려주는 행위, 전산망에 무단으로 접근하는 행위, 저작권을 침해하는 자료를 공유하는 행위를 금지한다. 위반 사실이 확인된 경우 계정을 정지하고 학생 상벌 규정에 따라 처리한다.

## 6. 개인정보 보호

과제와 프로젝트에서 개인정보가 포함된 자료를 다루는 경우 담당 교원의 사전 승인을 받아야 한다. 수집한 개인정보는 과제 종료 후 즉시 파기하여야 한다. 외부 서비스에 자료를 올리는 경우 민감한 정보가 포함되지 않았는지 확인하여야 한다.
