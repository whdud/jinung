# 과제 — 검색이 정답을 물어 오게 만들기

지능정보시스템 / 컴퓨터공학부

---

## 1. 무엇을 하는 과제인가

학칙·공지 문서 28건이 `docs/` 에 들어 있음.
질문 20개가 `questions.json` 에 들어 있음.

질문을 넣으면 **정답이 적혀 있는 조각**이 상위 5개 안에 들어오게 만드는 것이 목표임.

고치는 파일은 `solution.py` 하나뿐이고, 그 안의 함수도 두 개뿐임.

| 함수 | 하는 일 |
|---|---|
| `chunk(text)` | 문서 전문을 받아 조각 리스트로 자름 |
| `search(q, k)` | 질문을 받아 상위 k개 조각의 원문을 돌려줌 |

벡터 DB 는 쓰지 않음. 조각이 수십~수백 개 수준이라 numpy 로 전부 비교

## 3. 실행

```
python grade.py
```

이렇게 나옴.

```
조각 61개 — 임베딩 중 …

 1  휴학은 최대 몇 학기까지 할 수 있나      기본      O
 2  졸업하려면 학점을 얼마나 들어야 하나    기본      -
 ...

조각 수       61
Recall@5     14 / 20  =  0.700

틀린 문항 유형 : 동의어 3개, 조건 2개
자세히 보려면  : python grade.py --show 8
```

`O` 는 정답 조각을 가져온 것, `-` 는 못 가져온 것임.

틀린 문항이 무엇을 가져왔는지 보려면

```
python grade.py --show 8
```

조각 내용이 바뀌지 않으면 임베딩을 다시 하지 않고 `.cache/` 를 재사용함.
`chunk()` 를 고치면 자동으로 다시 계산함.

---

## 4. 채점 방식

```
Recall@5 = (정답 조각을 상위 5개 안에 가져온 질문 수) / 20
```

정답 판정은 **원문 구절의 부분 문자열 매칭**임.
`questions.json` 의 `answer_span` 이 가져온 조각 안에 들어 있으면 맞은 것으로 봄.
공백은 전부 지우고 비교하므로 조각을 어떻게 잘랐는지는 상관없음.

조각 ID 로 정답을 지정하지 않는 이유 — 사람마다 자르는 방식이 다르므로 ID 가 의미가 없음.

## 5. 무엇을 바꿔 볼 것인가

베이스라인은 **500자씩 기계적으로 자르는 것**이 전부임.
문장도 단락도 제목도 보지 않고, 오버랩도 없음.

한 번에 하나씩만 바꾸고 점수를 다시 잴 것. 두 개를 같이 바꾸면 무엇이 효과였는지 모름.

바꾸면서 점수를 메모해 두면 나중에 되돌리기 쉬움. 제출할 필요는 없음.

| 시도 | 바꾼 것 | 조각 수 | Recall@5 |
|---|---|---|---|
| 0 | 베이스라인 500자 | 61 | 0.700 |
| 1 | SIZE 300 | | |
| 2 | 1 + 오버랩 100 | | |
| 3 | 제목 경계로 자르기 | | |

---

## 7. 규칙

- `harness.py`, `grade.py`, `questions.json`, `docs/` 는 **고치지 말 것**
  - 채점은 조교 PC 의 원본으로 하므로, 고쳐도 점수에 반영되지 않음
- `search()` 는 **k개를 넘겨 돌려줄 수 없음**. 넘기면 채점이 중단됨
- `search()` 는 **조각 원문**을 돌려줘야 함. 조각 번호를 돌려주면 채점이 중단됨
- `answer_span` 을 코드에 넣어 맞히는 것은 0점임
- `questions.json` 을 `solution.py` 에서 읽는 것도 0점임
- 질문 문장을 조각에 섞어 넣는 것도 안 됨

내기 전에 `python grade.py` 가 끝까지 돌아가는지 확인할 것.
중간에 멈추면 그 상태로는 채점이 되지 않음.
